# Маленькие миры Runlith

Автономный интерактивный набросок. Открой `index.html` в браузере, сборка и установка не нужны. Все ресурсы локальные; сетевых запросов и интеграции с Runlith нет.

Три направления: тёплая студия, лесной лагерь и орбитальная станция. В каждом мире шесть вымышленных ИИ-персонажей ходят по проходам и останавливаются. Роли в интерфейсе иллюстративные, они не показывают состояние настоящих задач.

`concept-board.png` — отдельный художественный лист трёх направлений, созданный встроенным ImageGen. Он доступен по ссылке «Лист концептов» в прототипе. Это более детальный ориентир по атмосфере; интерактивный Canvas использует упрощённую графику, нарисованную кодом. PNG не используется вместо живой сцены.

Можно менять мир и фон независимо, включать тёмную тему, выбирать персонажа, скрывать имена, ставить анимацию на паузу и менять скорость. Системная настройка уменьшения движения запускает прототип на паузе. Скрытая вкладка останавливает цикл отрисовки.

Основное действие: сравнить три мира. Приоритеты: сцена, выбор эскиза, персонажи. Layout: sidebar + frame; на узком экране выбор эскиза располагается над сценой. Прокручивается документ. Дизайн самостоятельный, без внешнего референса.

Сцены — большие растровые диорамы `art/v2/*-wide.png` (ImageGen, прозрачный фон), персонажи — лист спрайтов `art/v2/agents.png` (12 кадров × 6 героев, ячейки 128 px). В `world.js` у каждой сцены есть проходимый пол, занятые зоны и точки взаимодействия (сидеть за столом, кофе, читать, пень с ноутбуком, гамак). Агент выбирает точку по роли, идёт по A*-маршруту, выполняет действие 7–15 с и идёт дальше. `render.js` оживляет сцену кодом: рябь воды, качание крон, огонь и дым, дым-пар, пыль, листья, пульс реактора, мерцание звёзд и экранов. `?debug` в URL показывает сетку прохода и точки.

Сцены — растровые изометрические диорамы `art/*.png` (сгенерированы ImageGen, фон прозрачный). Поверх Canvas рисует ходящих пиксельных персонажей; маршруты (сетка 0–12) проецируются на пол картинки параметрами `top/half/a/k` в `world.js`. Код: `world.js` — данные и движение; `render.js` — фон-картинка и персонажи; `app.js` — управление; `style.css` — оболочка. Canvas рисует геометрию в низком разрешении с `image-rendering: pixelated`. Данные не сохраняются после перезагрузки.

Проверка модели движения:

```sh
node --test prototypes/pixel-world/world.test.cjs
```

Для локального предпросмотра через HTTP, если нужно:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/pixel-world
```

Это эскиз элемента, не реализация UI приложения. Task ID / Execution Envelope не предоставлены; продуктовая версия, IPC, домены и Cargo workspace не меняются.

Проверки: 3 теста движения, синтаксис JavaScript, статические draft guard и sloplint. Реальный браузерный прогон и WCAG 2.2 AA не подтверждены: компьютерный браузер недоступен, а Chromium в текущей ограниченной среде завершается с сигналом 6. Адаптивность, фокус, пауза и reduced motion реализованы, но требуют проверки в обычном браузере. LSP не установлен; зависимости ради эскиза не добавлялись.

Промпт художественного листа: три изометрические пиксельные диорамы Runlith на кремовом фоне, уютная студия / лесной лагерь / орбитальная станция, маленькая команда человечков, единая камера, детальные предметы, собственные палитры; без интерфейса приложения. Использован встроенный ImageGen, не CLI.

## Графика не в git

PNG из `art/` и `concept-board.png` (около 16 МБ, сгенерированы ImageGen, повторить точно нельзя) в историю не входят: бинарники такого размера раздувают репозиторий навсегда. Без них Canvas не покажет сцены, поэтому прототип запускается только на машине, где эти файлы лежат локально.
